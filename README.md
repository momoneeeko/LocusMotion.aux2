# LocusMotion.aux2
トラックバー移動モードで使用できるカーブを作成するためのAviUtl2プラグイン

## 導入方法
1.[Releases](https://github.com/momoneeeko/LocusMotion.aux2/releases)から最新版の**LocusMotion.au2pkg.zip**をダウンロード

2.ダウンロードしたzipファイルをそのままAviUtl2のプレビュー画面にドラッグ&ドロップ

3."スクリプト・プラグインの追加"ポップアップが出たら任意で"このスクリプト・プラグインを信頼して使用する"をクリック

4.上部ツールバーから"表示"→"LocusMotion"を選択するとプラグインのウィンドウが表示されます。

## 概要
### 内容物
・Plugin\LocusMotion.aux2 - ウィンドウを追加する汎用プラグイン<br>
・Script\LocusMotion.tra2 - トラックバー移動スクリプト

### 作成した曲線の適用方法
- #### プラグインウィンドウ内で適用
1.オブジェクトを選択して導入したい項目名をエフェクト一覧画面に表示させる<br>
2.項目名または曲線プレビューにエディタ上の何もない場所からドラッグ&ドロップ
(曲線プレビューにD&Dしたら区間ごとに曲線を適用させられます)
- #### トラックバー移動モードを選択して適用
1.トラックバー移動モードがLocusMotionでない状態からLocusMotionを選択すると現在エディタに表示されている曲線が全ての区間で適用されます。
- #### トラックバー名を左クリックして適用
1.オブジェクト設定の項目名を左クリックをする<br>
2."プラグイン"→"LocusMotion"をクリックすると現在エディタに表示されている曲線が全ての区間で適用されます。

### エディタ画面について
この画面で曲線の形を作ることができます。<br>
上部モード選択タブから選択中の曲線のモードを"ベジェ曲線","エラスティック","バウンス"から変更できます。<br>
ダブルクリックで曲線を追加することができます。<br>
ホイール操作でエディタ画面の拡大/縮小、視点移動ができます。<br>
ハンドル操作+Shift ― ハンドルをスナップしながら移動できます。<br>
ハンドル操作+Ctrl ― 2つのハンドルを対称的に移動できます。(ベジェ曲線モードのみ)<br>
ハンドル操作+Alt ― 2つのハンドルを連動させて移動できます。(ベジェ曲線モードのみ)
### イージング選択機能について
エディタ画面上で左クリックして、メニューから"イージングを選択"を選択すると41個のイージングを選ぶウィンドウが表示されます。好きなイージングをクリックすると選択中の曲線が"イージングモード"になり、選んだイージングが適用されます。

### エフェクト一覧画面について
選択中のオブジェクトのエフェクト/項目が表示されます。<br>
項目をクリックすると適用された曲線を見ることができます。

### モディファイア機能について(現在は未実装です)
エフェクト一覧画面の曲線プレビューを右クリックして、メニューから"モディファイア"を選択するとモディファイアが追加できるウィンドウが表示されます。<br>
"+"ボタンから好きなモディファイアを選択すると上部に適用するモディファイアが一覧で表示されます。<br>
✕からウィンドウを閉じると選択していた区間の曲線にモディファイアが実際に適用されます。
